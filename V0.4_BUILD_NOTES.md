# JalalAI v0.4 — Provider + Research Layer

## Added
- Provider-neutral adapters for OpenAI Responses API, Anthropic Messages API, and Google Gemini REST API.
- Environment-only API key configuration; no secrets in source.
- Model capability catalog.
- Web search abstraction and evidence conversion.
- In-memory memory abstraction for the first retrieval contract.
- Minimal HTTP API: `GET /health`, `POST /v1/tasks`.
- Router can measure provider reliability/latency and fall back to other registered providers.

## Important
The local demo provider remains available so the project can build and run without paid credentials. Real providers activate only when their environment variables are configured.

OpenAI integration follows the current Responses API pattern and supports text input/output. Web search and file search are capabilities available in the platform, but JalalAI keeps provider-specific tools behind its own tool layer rather than making OpenAI the system of record.

## Still not production
Authentication, persistent database/vector memory, robust search parsing, streaming API, browser automation, Android UI, and comprehensive policy/approval controls remain next milestones.
