# JalalAI Android Release Scaffold

This directory defines the Android release contract while keeping the audited web/core implementation intact.

## Required screens

- Splash and onboarding
- Login/register/recovery
- Home and AI Chat
- Voice input
- Research
- Expert Agents
- Files and Office tools
- Creative Studio
- Projects and Knowledge Vault
- Notifications
- Profile, security and subscription

## Required production integrations

- Secure authentication/session storage
- HTTPS API client
- Upload/download and background task status
- Push notifications
- Google Play Billing and server-side purchase verification
- Crash reporting and analytics with disclosed privacy behavior
- Android App Bundle signing

This is a source-level release scaffold, not a signed production AAB or Play Store-approved application.
