# JalalAI v0.5 — Research, Critic & Self-Correction

v0.5 upgrades the v0.4 provider-neutral foundation with a research/evidence path, persistent JSON memory, critic review, and a bounded self-correction loop.

## Flow
USER -> PLANNER -> RESEARCH -> SPECIALISTS -> CRITIC -> SELF-CORRECTION -> VERIFIER -> MEMORY

## Guardrails
- No API keys are stored in source.
- Verified mode fails closed when research is unavailable or evidence remains insufficient.
- Self-correction is bounded to two iterations to avoid runaway loops.
- Memory is local JSON by default; production should replace it with SQLite/vector storage.

## Not yet production
- Search HTML parsing is intentionally lightweight; production should use a supported search API/browser.
- Memory is lexical JSON, not semantic vector RAG yet.
- Authentication, rate limiting, streaming, UI, and Android are still next layers.
