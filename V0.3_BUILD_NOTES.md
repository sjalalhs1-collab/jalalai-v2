# JalalAI v0.3 — Build Notes

## What changed from v0.2
- Fixed the v0.2 TypeScript issue caused by the Node crypto import and untyped evidence array.
- Added a working local demo provider so the orchestration pipeline can run without API keys.
- Added provider health + measured reliability/latency routing rather than always selecting the first provider.
- Added domain aliases so planner detection is less dependent on exact domain words.
- Added actual specialist-step execution through the router.
- Added web.open tool with explicit permission checks.
- Added verified-mode evidence requirement.
- Added tests for the 34-domain registry and planner/verification behavior.

## Known limitations
- LocalDemoProvider is a development stub, not an AI model.
- Web search is not yet implemented; web.open only fetches a supplied public URL.
- Evidence extraction is not yet connected to search results.
- Memory/RAG persistence is not yet implemented.
- Real provider adapters and secret management are still required.
