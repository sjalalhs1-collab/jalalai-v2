# JalalAI v0.7 — Research Intelligence Core

Added on top of v0.6:
- stronger DuckDuckGo result parsing with redirect handling and snippets
- authority/relevance source ranking
- page-to-evidence extraction from retrieved documents
- vector RAG index abstraction with deterministic local fallback embeddings
- semantic evidence retrieval during specialist execution
- stronger multi-agent textual agreement/disagreement scoring
- hardened task API input validation and v0.7 health metadata
- regression tests for vector retrieval, evidence ranking, extraction, and empty-search safety

Reality check:
- HashEmbedding remains a deterministic fallback, not a production semantic embedding model.
- Search quality depends on upstream search availability and page accessibility.
- Debate is a structured consensus signal, not proof of factual correctness.
- Authentication/rate limiting are basic API protections, not a complete production security boundary.
