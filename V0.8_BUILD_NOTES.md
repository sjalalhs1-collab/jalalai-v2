# JalalAI v0.8 — Web Command Center

## Delivered
- Browser-based Command Center served by the same Node backend.
- Fast / Deep / Verified task modes.
- Task-scoped SSE events so one browser session does not receive another task's execution events.
- Live execution timeline, final answer, confidence, and evidence/source panel.
- Health endpoint updated to v0.8.0.
- Request body and input-size limits plus baseline security headers.
- Removed packaged demo memory state to prevent recursive/cross-run memory contamination.

## Important limits
- Provider token streaming is not yet implemented; the UI streams execution events, not model tokens.
- Vector RAG is still transient and uses the deterministic local embedding fallback unless a production embedding/vector backend is added.
- Web search currently relies on the existing search abstraction and should move to a supported production search/browser provider.
- Authentication and rate limiting remain baseline protections.

## Verification target
Run `npm run build`, `npm test`, and `npm run demo`. The packaged tree must not contain `data/jalalai-memory.json` populated with prior demo output.
