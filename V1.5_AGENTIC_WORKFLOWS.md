# JalalAI v1.5 — Agentic Workflows

Adds a durable workflow layer above the v1.4 Knowledge Fabric.

## Added
- Persistent workflow state in `JALALAI_WORKFLOW_PATH`.
- Sequential multi-step autonomous workflows (1–20 steps).
- Step-level task IDs and lifecycle state.
- Bounded retry: failed steps retry up to three attempts.
- Startup recovery: interrupted `running` workflows return to `queued`.
- Workflow inspection/list/cancel APIs.
- Existing Knowledge Vault, RAG, model routing, streaming, tools, research, verification and task manager remain available.

## API
- `POST /v1/workflows`
- `GET /v1/workflows`
- `GET /v1/workflows/:id`
- `DELETE /v1/workflows/:id`

## Reality check
This is durable local workflow state, not a distributed queue. For production scale, move workflow state to PostgreSQL/Redis and execution to isolated workers.
