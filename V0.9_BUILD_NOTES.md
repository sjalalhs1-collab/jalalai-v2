# JalalAI v0.9 Build Notes

## Delivered
- Browser file intelligence for text-readable files (.txt, .md, .json, .csv, .log, .xml, .html, .js, .ts, .py, .sql).
- Client-side file reading keeps raw files out of the backend unless the user explicitly submits their extracted text.
- Attachment size/count limits and request-size hardening.
- Task-scoped file events in the Command Center timeline.
- `/v1/models` model/provider inventory endpoint.
- Health metadata expanded with file-intelligence and model-inventory capabilities.

## Honest boundary
This release does not claim native PDF/DOCX/XLSX parsing or true provider token streaming. Those require dedicated parsers/stream adapters and are the next engineering layer.
