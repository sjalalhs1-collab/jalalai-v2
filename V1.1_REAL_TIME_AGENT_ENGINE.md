# JalalAI v1.1 — Real-Time Agent Engine

## Delivered
- Provider-level streaming interface with OpenAI Responses SSE, Anthropic Messages SSE, and Gemini streaming SSE adapters.
- Router streaming with bounded provider fallback and measured health/reliability/latency scoring.
- Parallel execution of independent planner steps in bounded batches of four.
- AbortSignal propagation through task execution and provider HTTP calls.
- Task cancellation API: `DELETE /v1/tasks/:id`.
- Task-scoped SSE now includes `token` events containing expert output deltas.
- Web Command Center renders live expert tokens and provides a Stop control.

## Verification
- TypeScript build passes.
- Full automated suite passes (16 legacy/regression tests + 3 v1.1 tests).
- Live API smoke test should be run with `npm run server`; real token streaming requires at least one configured provider API key.

## Important boundary
When no external provider key is configured, the local demo provider remains available for deterministic testing. It is not an AI model and its output is explicitly labeled DEMO MODE.
