# JalalAI v0.6 — Production Intelligence Core

Build layer added on top of v0.5:
- deterministic local vector index + embedding abstraction
- browser page retrieval
- improved evidence ranking
- expert debate/consensus signal
- event bus + SSE endpoint
- bearer-token auth option
- per-client rate limiting
- explicit web permission enforcement
- expanded public exports

Reality check: HashEmbedding is a deterministic fallback, not a semantic embedding model. Production RAG should plug in a real embedding provider/vector database. SSE is an event stream; task execution remains request/response in this version.
