# JalalAI v1.0 — Final Core Build

## What is finalized
- Web Command Center UI
- Master orchestration and 34 expert-domain registry
- Fast / Deep / Verified modes
- Research + browser retrieval + evidence extraction
- Evidence ranking and fail-closed Verified mode
- Local persistent JSON memory foundation
- Deterministic local vector index foundation
- Expert debate / consensus signal
- Critique + bounded self-correction
- Task-scoped Server-Sent Events
- File/text attachment intelligence with size/type validation
- Provider inventory
- Multi-provider routing with measured reliability/latency scoring
- Bounded provider fallback when a selected provider fails
- Optional bearer authentication and per-client rate limiting

## Deliberately not claimed as production-complete
- Native PDF/DOCX/XLSX parsing is not yet included.
- True token-by-token provider streaming is not yet exposed by the provider contract.
- DuckDuckGo HTML search is a compatibility foundation, not a guaranteed production search service.
- The local hash embedding is deterministic fallback RAG, not a semantic embedding model.
- Debate/consensus is a signal, not proof of truth.
- Authentication and rate limiting are baseline protections, not a full enterprise security program.

## Run
```bash
npm install
npm run test
npm run server
```
Open `http://localhost:8787`.

## Real providers
Set one or more environment variables:
- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
- `GOOGLE_API_KEY`

Optional: `OPENAI_MODEL`, `PORT`, `JALALAI_API_TOKEN`, `RATE_LIMIT`.
